# Contributing to Applygrove

Thanks for caring about calmer job searches. We especially welcome bug fixes, accessibility improvements, translations and thoughtful workflow simplifications.

1. Discuss large changes in an issue before investing significant time.
2. Use a feature branch; make focused commits with a clear explanation.
3. Run `npm ci --ignore-scripts && npm run verify` on Node.js 22 or newer.
4. Test keyboard operation, 375 px layouts, and desktop layouts for UI changes.
5. Open a pull request with a summary, how you tested it, and screenshots if relevant.

Do not add trackers, account systems, analytics, new dependencies, external AI providers or data uploads without clearly reviewing their privacy consequences and discussing them first. Keep code readable and dependency-free where reasonable.

Never attach real application documents, private contact details, sensitive job offers, tokens or credentials to public issues or PRs. Use fictional information in screenshots and tests.
