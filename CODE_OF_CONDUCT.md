# Code of conduct

Applygrove welcomes people of all backgrounds and skill levels. Be respectful, curious, and constructive. Harassment, discriminatory comments, doxxing, intimidation, spam, and unsolicited promotional messages are not accepted.

For security concerns, see [SECURITY.md](SECURITY.md) and disclose privately. For abusive or threatening GitHub activity, use GitHub's report feature. Maintainers may moderate or remove material that violates this code of conduct.
