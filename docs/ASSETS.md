# Asset provenance

- `hero.webp` and `hero-small.webp`: an original, generated editorial workspace photograph, included locally in this repository.
- `landing-preview.png`: product screenshot used for the social preview and README, within the 750 KB release asset budget.
- `social-card.png`: original full-resolution composition retained as a source asset; it is not included in the production build.
- `favicon.svg`, `icon-192.png`, `icon-512.png`: original minimal leaf mark made for this project.
- `desktop-preview.png`, `mobile-preview.png`: screenshots of the actual Applygrove interface, using fictional sample job opportunities.

There are no externally fetched runtime photographs, font CDNs, stock assets or third-party brand logos. No claim of registered trademark rights is made; maintainers should verify the name before commercial use.
