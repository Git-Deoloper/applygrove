GOOD TO KNOW

Clear answers.
Less guesswork.

Is Applygrove really free?

Yes. This open-source version is free to use, with no account, premium tier or paid integration required.

Where is my information stored?

In this browser's local storage on your device. We don't operate an account server or sync it anywhere. Export regular JSON backups so clearing browser data doesn't erase your work.

Does it send follow-up emails or apply for jobs automatically?

No. You remain in control. Applygrove keeps track of the process and can help you draft a message you can review and send yourself.

Can I use it across devices?

There is no cloud sync. Export a JSON backup and import it on your other device. Anyone who has that file can read its contents, so store it carefully.
